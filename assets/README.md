# Assets Directory

This directory contains game assets imported into Godot:

- `models/`: 3D models (`.glb`, `.gltf`) organized into `characters/`, `devices/`, `stations/`, `workshop/`
- `textures/`: Textures and materials (`materials/`, `ui/`)
- `audio/`: Sound effects (`sfx/`) and background music (`music/`)
- `fonts/`: Font files (`.ttf`, `.otf`)
- `shaders/`: Godot visual and text shaders (`.gdshader`)
- `raw/`: Source art files (e.g. `.blend`, `.xcf`, `.psd`) excluded from Godot import via `.gdignore`
